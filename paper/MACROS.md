# Paper Macro Reference

Every experiment-derived number in the paper is a LaTeX macro
defined in `paper/_numbers.tex`. That file is auto-generated by
`experiments/extract_paper_numbers.py` from the JSON outputs in
`results/`.

This document lists every macro, what it means, which experiment
fills it in, and what the macro's current value is in the released
sandbox run (so you can sanity-check whether your numbers are in the
right ballpark).

## Workflow

1. Run experiments (any subset; see `EXPERIMENTS_TO_RUN.md`).
2. `python experiments/extract_paper_numbers.py` -- regenerates
   `paper/_numbers.tex` from whatever JSONs are present. Macros for
   missing experiments are left as `TBD`.
3. Pass URLs on submission day:

       python experiments/extract_paper_numbers.py \
           --demo-url https://your-demo-url \
           --video-url https://your-video-url \
           --repo-url  https://your-repo-url

4. `pdflatex && bibtex && pdflatex && pdflatex` in the `paper/`
   directory to compile.

If a macro is still `TBD` when the paper compiles, the literal
string `TBD` will appear in the PDF, which makes it impossible to
miss during a final pre-submission review.
